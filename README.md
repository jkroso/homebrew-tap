# jkroso's Homebrew tap

Apps by Jake Rosoman, for [Homebrew](https://brew.sh).

| Cask | What it is |
|---|---|
| [derivate](Casks/derivate.rb) | [Derivate](https://github.com/jkroso/derivate), a menu bar app that makes your passwords from your name and secret |

Install one with:

```sh
brew install --cask jkroso/tap/derivate
```
